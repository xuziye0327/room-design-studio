# 浅框装饰方案

> 双人办公与公路车收纳空间｜方案设计交付
>
> 本方案与另外两套方案共用房间、桌子、南墙及基础电位条件，北墙展示设计独立保留。

以错落展示柜和整体定制背板组织办公收纳，在中间柜体下方加入薄框装饰画，点缀墙面留白。画面可采用抽象、风景、摄影或个人收藏内容。

## 1. 空间与使用条件

| 项目 | 设计依据 |
|---|---|
| 房间 | 北墙宽280 × 进深220，层高280；面积约6.16㎡ |
| 使用者 | 两人同时长期办公，身高约160–180 |
| 桌子 | 一体固定长桌，长240 × 深80 × 完成面高75 |
| 桌子位置 | 北墙居中，左右各留约20 |
| 设备 | 两台台式机、四台32英寸显示器；每人一横一竖，竖屏位于中部 |
| 主机位置 | 各自工位右手侧、桌下落地 |
| 收纳内容 | 大小手办、少量书籍、数码配件与线材 |
| 南墙功能 | 整辆公路车壁挂、浅书托与装饰画 |

**阅读口径：**除另注明外，尺寸单位为厘米。桌子尺寸与布局方向为本次采用的设计条件；柜体、层板、藏品、机箱、自行车及电位坐标为示意尺寸，须在定制深化时核对。板厚、五金与隐藏固定节点以承重及加工设计为准。

家具效果图统一展示椅子收进桌下的状态。主机按约21×42×46的体量占位；显示器支架、办公椅款式与颜色为示意。

### 中部浅框装饰

| 项目 | 本方案表达 |
|---|---|
| 尺寸 | 约宽60×高30，框体厚约1.6 |
| 高度与位置 | 底部离地约175；距西墙100–160 |

## 3. 南墙：公路车与阅读展示

[打开南墙HTML效果图及源码](html/南墙公路车与阅读展示.html)

三套方案采用相同南墙布置：自行车位于南墙偏西，书托在车身上方，装饰画位于右上方。

| 项目 | 位置与参考尺寸 |
|---|---|
| 公路车 | 整车低位横挂；参考长175、高100、把横宽44 |
| 挂车位置 | 整车横向范围约距西墙10–185；轮胎离地约15 |
| 空间占用 | 最大突出墙面暂按45，须按实车及挂架核对 |
| 浅书托 | 宽90 × 深15；底部离地暂按145；横向范围约距西墙20–110 |
| 装饰画 | 宽65 × 高85；底部离地暂按143；细框、浅色画面 |
| 椅子收拢 | 图中按向桌下前移约35示意，实际收拢能力取决于实椅和桌架 |

**使用方式：**取放自行车前，将两把椅子推回桌下；拿书时避开车身。南墙视图隐藏北墙柜体、洞洞板和桌面设备，以显示南墙布局。

**取放验证：**需用实车确认脱钩、抬起、平移、转向和出门的连续动作，并核对骑行车辆与常态办公坐姿的净空。挂架接触方式应匹配实车材质与管型，墙体固定按实际重量及安装条件设计。静态示意图不构成上述动作或承重已经验证的证明。

## 4. 电位与网络

[打开电位与网络HTML图及源码](html/电位与右侧网络.html)

三套方案采用一致的基础电位。电位图家具仅保留桌子，桌面半透明，以展示墙面插座和桌下交换机。

### 4.1 办公用电

| 区域 | 左工位 | 右工位 | 中心高度 |
|---|---:|---:|---:|
| 桌面上方墙插 | 3个五孔 | 3个五孔 | H=90 |
| 桌下墙插 | 4个五孔 | 4个五孔 | H=55 |

办公区共14个五孔插位。桌面上方墙插用于常用充电与临时设备；桌下各3个用于主机与双屏，左侧第4个备用，右侧第4个为交换机常供电。

墙面底盒独立固定，定制洞洞板配合插座面板预留开口。家具效果图表达空间和饰面，插座具体位置以本节电位示意图为准。

### 4.2 定位表

以室内西北角地面为原点：**x向东，y向南，H为距完成地面的中心高度**。以下坐标为方案定位值，单位为厘米。

| 编号 | 内容 | 平面位置 | H |
|---|---|---|---:|
| U1–U3 | 左工位桌上墙插 | 北墙，x=45 / 60 / 75 | 90 |
| V1–V3 | 右工位桌上墙插 | 北墙，x=210 / 225 / 240 | 90 |
| A1–A4 | 左工位桌下墙插 | 北墙，x=90 / 100 / 110 / 120 | 55 |
| B1–B4 | 右工位桌下墙插 | 北墙，x=210 / 222 / 234 / 246 | 55 |
| W1 | 右侧单口网络面板 | 北墙，x=170 | 55 |
| L1 | 展示柜灯供电 | 北墙，x=50；柜内可检修位置 | 220 |
| C1 | 顶面主灯预留 | x=140，y=110，即房间中心 | 280 |
| K1 | 入门双键开关 | 东墙，y=120；距示意门洞北边约20 | 120 |
| S1 | 清洁、临时充电通用五孔 | 西墙，y=195；距南墙约25 | 30 |

K1分别控制主灯和展示柜灯，柜灯驱动留可检修位置。L1后的低压灯线按本方案柜型分支安排。

### 4.3 交换机与走线

```text
家中路由器／弱电箱
        │
  右侧网络面板 W1
        │
桌下右后方交换机 SW1
        ├── 左侧台式机
        └── 右侧台式机
```

- 交换机放在桌下右后方的独立通风托盘内，网口朝房间内侧。
- 托盘参考宽30 × 深20，底部离地约58；占位范围为x=185–215、y=18–38。
- B4给交换机常供电。适配器固定在独立供电区域，保证检修与散热空间。
- 强弱电分管、分底盒，桌下分区理线；线条只表示连接关系。
- 插头、充电器、屏幕升降、支架转动及线缆弯折需结合实物核对。线径、回路、负荷、接地和保护配置由电工结合现有配电及适用规范确定。

## 5. 饰面与实施边界

- **桌面与层板：**白橡木色、哑光表面，兼顾耐磨与清洁；基材与饰面做法在定制深化时确定。
- **柜体：**暖白色；玻璃展示门与柜内柔和照明用于突出手办。柜内照明的亮度、色温和遮光结合样品调整。
- **五金与固定：**柜体、开放层板及洞洞板分别按荷载确定固定方式，支撑尽量隐藏；现场先明确墙体类型和可固定位置。
- **坐姿与拿取：**75高固定桌面配可调座椅，结合两位使用者验证坐姿。高位柜与层板以展示、低频取用为主；实际拿取高度需试用确认。

### 落地前核对清单

1. **房间与门窗**：复核净尺寸、墙面垂直度、插座所在墙面、门洞及门扇。原户型的门洞70、门侧短墙10为暂定值；窗宽和位置按原图示意，窗台90、窗高120为绘图假设。
2. **家具和设备**：确认桌架结构、板材跨度与抗下挠，柜体和层板承重，机箱尺寸与散热，显示器及夹装支架的净空。
3. **手办与书籍**：逐件确认大手办的高度、底座深度和重量，结合书籍荷载调整层板与展示格。
4. **椅子与自行车**：核对实椅能否收进桌下，扶手、脚轮与桌架、机箱的避让；验证挂车固定和完整取放路线。
5. **电位与灯光**：确认墙插操作空间、洞洞板开口、墙内管线与家具固定孔的避让，以及柜灯驱动检修和灯线分支。

**交付层级：布局与视觉设计说明、电位位置示意。**完成现场复尺、结构及电气深化和设备取放验证后，再确定加工、采购与施工尺寸。本文件不替代施工放样图、承重计算或电气施工设计。
